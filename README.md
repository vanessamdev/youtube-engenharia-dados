# YouTube Top 100 Songs 2025 - Análise com PySpark

Projeto de análise de dados utilizando PySpark e SQL para identificar as 25 músicas mais tocadas do YouTube em 2025.

## Requisitos

- Python 3.8+
- Java 8 ou 11 (necessário para PySpark)
- PySpark

## Instalação

```bash
pip install -r requirements.txt
```

## Estrutura do Projeto

```
├── INFO/                    # Documentação do projeto
│   └── projeto_info.md
├── analise_youtube.ipynb    # Notebook com a análise
├── youtube-top-100-songs-2025.csv  # Dataset
├── requirements.txt         # Dependências
└── README.md
```

## Execução

1. Instale as dependências
2. Execute o notebook `analise_youtube.ipynb`
3. O resultado será salvo em `top_25_musicas_2025.txt`
